# Agent 与调用的数据归属

Chat 容纳用户任务；Model Call 属于 Agent，Tool Call 属于 Model Call。沿关系派生归属、聚合回答、错误和活动，避免重复副本与同步逻辑。服务方协议 ID 不替代本地实体身份；子任务来源见 [ADR 0002](0002-sub-agent-ownership.md)。

Project 与 Chat 拥有当前配置，Agent 不复制；执行时读取配置，Model Call 保存实际发送的请求，已发请求不随配置变化而改变。

Root 提交正文按当时配置的 API key 与 MCP 环境变量脱敏后保存；空值不参与替换。原始正文仅由现有运行状态持有以执行当前任务，结束后释放，不从脱敏展示内容重建当前输入，也不另存持久副本。后续任务的历史继续来自脱敏记录；用户图片保留原生字段与字节。

成功调用的脱敏完整响应是唯一输出依据，展示、复制、任务结果及协议续接均由它派生，防止界面和后续模型输入使用不同结果。失败或中断保留暂存内容；成功后不合并最终响应省略的内容。

记录脱敏区分应用／Responses 的具名结构与内容：仅在实际协议位置保留已识别的字段和类型标记，正文、未知服务方扩展及任意工具／MCP payload 的键和值继续脱敏。用户／工具图片的原生内容数组与 MCP 连接状态按各自已知结构记录，仅原生图片字段的字节不作文本替换，普通文本／JSON 中的 data-image 前缀不授予豁免；Command Output 入口依赖的内置工具名在 Tool Call 名称位置保留。此处理只修正现有记录，不另存成功输出副本；实际执行输入不由脱敏展示内容重建。

各层拥有自己的状态与错误。成功 Model Call 不因 Agent 达到执行上限而变为失败，Agent 也不复制调用错误。本地不自动重试付费调用。

后续根任务按 Chat 执行顺序载入此前所有 Root 的问题及原生用户图片。成功 Root 继续只带问题与权威回答；失败／取消 Root 则从现有 Agent、Model Call、Tool Call 和创建关系派生该 Root 及后代的实际终态、错误、参数／结果、已完成输出与明确标注的未完成暂存内容，在更后的 Root 中仍保留。原问题只出现一次，不复制进新 prompt、不嵌套旧 HTTP 请求、不另存历史快照或调用总结模型。

中断记录仅作为历史资料，不派发旧函数、不执行不完整参数、不重放副作用，也不声称 Stop 撤销了修改。保留旧 Tool Result 返回时的 running 事实，同时提供清理后的最终 command state；旧 session 不可恢复。按需通过 read_tool_output 读取同 Chat 的历史命令日志，保留现有单次输出预算、分页及流顺序，不自动扩展完整日志。工具图片只标明原记录中存在，不将 base64 作为普通文本携入后续 Root。同一 Agent 继续保留完整工具协议上下文，实际输入已在请求记录中。

采用单一当前数据库结构，不维护迁移分支；启动拒绝不支持的数据库，保留用户数据。管理授权边界见 [ADR 0004](0004-command-tool-isolation-boundary.md)。

数据库保护保留现有普通文件系统权限检查，防止同机其他账号访问数据；不防御当前账号下的恶意进程、管理员或已失陷的系统，不增加加密或额外安全框架。数据库文件经符号链接指向共享可写目录的额外校验暂缓，接受用户主动选择此类存储位置的边界风险。

同一文件数据库只由一个服务实例拥有：规范化相对／绝对路径与符号链接，在打开主库和启动中断处理前，先在独立 SQLite 所有权文件中取得独占事务；主库仍可供记录读取。所有权持续到执行清理和主库关闭后，正常退出释放，进程死亡由系统释放，残留文件不代表占用。独立数据库与内存实例互不阻挡。同端口主动替换等待旧进程清理退出后再启动；真正重启保留 Agent／Model Call／Tool Call 的中断事实，不重放命令或模型请求。
